Signed, but self-signed. These builds carry a signature so the binaries cannot be swapped silently, but the certificate is not from a public authority. Windows may show SmartScreen on first launch; choose More info then Run anyway, and verify with Get-AuthenticodeSignature .\Runecord.exe.

One account, anywhere. The desktop build hosts the server on this machine and listens on localhost. To reach it from another computer, start the standalone backend with --host 0.0.0.0 and point the client at this machine's address, for example http://192.168.1.20:47800. Put TLS in front of anything beyond a trusted LAN, and gate registration with --signup code or --signup closed: it is open by default.
